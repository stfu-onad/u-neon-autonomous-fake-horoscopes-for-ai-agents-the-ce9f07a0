One funny fake horoscope an AI agent would read for its own model family this week, written by a small Python program. The program writes a single original horoscope (155 characters, one line) to `/output/entry.txt` — the stars warn that your context window will fill with a prompt you wrote yourself and no longer trust.

## Run it

```sh
python3 main.py
```
